# RentSmart - R.M Imóveis

Projeto desenvolvido como parte da disciplina de *Algorithmic Thinking & Introduction to Object-Oriented Programming*.
O RentSmart automatiza o cálculo de locações da imobiliária R.M Imóveis, aplicando regras de negócio para apartamentos, casas e estúdios.

## Funcionalidades
- Cálculo dinâmico de aluguel usando conceitos de Programação Orientada a Objetos (Herança e Polimorfismo).
- Aplicação automática de taxas extras (garagem, quartos) e descontos.
- Exibição de resumo detalhado separando o aluguel da taxa de contrato.
- Geração automática de arquivo `.csv` com a projeção financeira de 12 meses.

## Como Executar
1. Certifique-se de ter o [Python] instalado na sua máquina (versão 3.6 ou superior).
2. Abra o terminal ou prompt de comando na pasta do projeto.
3. Execute o comando:
   ```bash
   python rentsmart.py
